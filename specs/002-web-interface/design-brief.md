# Дизайн-бриф — Веб-интерфейс помощника поддержки МИСИС (v2, светлая тема)

> Ревизия 2026-09-12: направление изменено заказчиком — светлая тема, фирменный синий МИСИС, лёгкий liquid glass. Этот файл — источник правды для UI фичи 002.

## 1. Общий стиль

- **Тема**: светлая. Фон приложения — холодный серо-голубой `#EDF1F8`; поверхности — белые `#FFFFFF`; карточки — плоские в покое, граница hairline `rgba(10,30,100,.10)`, тень только на hover/подъёме.
- **Liquid glass (слабый)**: только там, где есть реальная глубина — липкая шапка поверх контента, оверлей модалок, статус-борд. Формула: `background: rgba(255,255,255,.78)` + `backdrop-filter: blur(14px) saturate(1.3)` + граница `rgba(255,255,255,.9)` поверх hairline. Fallback — непрозрачный белый.
- **Бренд**: синий МИСИС `#0047FF` (≈ родной `#0541F0` с misis.ru) — единственный акцент. Чернильный navy `#0A1E64` — основной цвет текста (взят с сайта).
- **Декоративный фон**: два мягких размытых пятна (brand/mint, 4–6% непрозрачности) за контентом — чтобы у стекла было что размывать. Не градиентная идентичность.
- **Характер**: рабочий пульт демо. Плотные карточки, видимые статусы. Не маркетинговый лендинг.
- **Типографика**: Golos Text (400/500/600/700, кириллица) — интерфейс; JetBrains Mono (400/500) — номера тикетов `SUP-2026-*`, время, терминал, цифры метр. База 15px/1.55, заголовки 20–28px, крупные цифры 36–44px, `font-variant-numeric: tabular-nums` в таблицах и метриках.
- **Лого**: место в шапке 36×36 — плейсхолдер до получения официального файла (финальный файл от заказчика).

## 3. Иконки

Только SVG, единый stroke 1.8px, без эмодзи нигде. В прототипе — hand-made inline SVG; в React-версии — `lucide-react` (одна зависимость, tree-shaking). Набор: bot, book, file-text, user (маршруты); wifi, globe, grad-cap (сервисы); alert-triangle, bell, lock, login/logout, send, sparkles (ИИ), check, x, chevron-down, refresh, wrench, chart, clock, arrow-right.

## 4. Моушн

- Только `transform`/`opacity`; явные свойства, никакого `transition: all`.
- Ease-out входа `cubic-bezier(.23,1,.32,1)`; hover/feedback 100–150мс, карточки 200–350мс, модалка 300мс, смена view 250мс.
- Вход карточек: `opacity 0 + translateY(8px) + scale(.98)`; stagger 40–70мс, максимум 8 элементов.
- Кнопки `:active { scale(.97) }`; hover-эффекты только под `@media (hover:hover) and (pointer:fine)`.
- Состояния: спиннер «Агент разбирает обращение…» (три точки), пульс красной лампочки при сбое, мигание строки очереди при обновлении, slide-in тоста, появление сообщений чата.
- `prefers-reduced-motion: reduce` — оставляем только opacity-фейды.

## 5. Экраны (без изменений по составу)

Состав экранов и блоков — как в ревизии 1 (вход, форма+диалог, кабинет, админка: очередь/эскалация/заказы/инструменты/метрики). Отличия только в оформлении: светлая тема, glass-шапка, SVG-иконки, цветовая семантика из п.2. Wi-Fi сети называются как в ядре: **MISIS-EDU, MISIS-CORP, MISIS-Guest**.

## 6. Ключевые экраны — композиция

- **Форма обращения**: сетка 420px + 1fr; слева форма и 8 чипов-примеров, справа карточка результата (badges + обоснование + подзадачи + ответ агента), ниже — диалог. Красная плашка сбоя — заметный блок с alert-иконкой. Плашка `auth_required` — жёлтая, с кнопкой входа.
- **Очередь оператора**: красный баннер инцидента сверху; таблица (приоритет, маршрут, описание, канал, статус, время); статус-борд из 5 лампочек — стеклянная панель; индикатор «обновлено только что».
- **Карточка эскалации**: саммари → проверки → рекомендация → почему эскалировано → исходник+перевод (свёрнуто) → журнал (свёрнут); правая колонка — действия. Читается ≤30 сек.
- **Метрики**: асимметричный бенто — крупная карточка % автоматизации на 2 колонки, рядом время реакции и инциденты, снизу полоса счётчиков.
- **Инструменты**: терминальный вывод — тёмная «экран-в-экране» панель (navy фон, мятный/белый текст), допустимо в светлой теме.
