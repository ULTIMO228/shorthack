# Phase 1 — Quickstart: веб-интерфейс (002)

## Запуск

```bash
# 1) Ядро (001) — обязательно запущено, см. specs/001-misis-support-assistant/quickstart.md
cd backend && .venv/bin/uvicorn app.main:app --reload   # :8000

# 2) Фронт (Next.js, App Router)
cd frontend && npm install && npm run dev               # :3000, прокси /api → :8000 (next.config.ts rewrites)
```

Проверка сборки: `npm run build` — без ошибок.

## Сценарии проверки (соответствуют SC спеки 002)

1. **Вход**: открыть :3000 → кнопка «Войти по почте МИСИС» в шапке; `ivanov@misis.ru` → интерфейс с ФИО/группой; F5 → сессия на месте; `x@gmail.com` → ошибка домена под полем.
2. **Обращение с диалогом**: кнопка примера «Wi-Fi» → результат с badges (маршрут/приоритет/обоснование); статус «ждёт ответа» → ввод активен; ответ → продолжение без потери контекста.
3. **Плашка сбоя**: оператором в `/admin/tools` выключить MISIS-EDU → студентом повторить пример → красная плашка «сбой известен» (≤ 2 c после ответа ядра).
4. **Кабинет и справки**: заказ справки с места учёбы из каталога → в «моих заказах» статус «не обработана»; оператором в `/admin/certs` сдвинуть статус → у студента обновилось без F5 (polling).
5. **Эскалация**: вопрос вне базы → в `/admin` запись со значком «Оператор»; карточка — саммари/проверки/рекомендация; закрыть с «в БЗ» → черновик → подтвердить.
6. **Инцидент**: «Волна жалоб» в `/admin/tools` → баннер в `/admin` → «Уведомить затронутых» в карточке → sent ≥ 3; метрики в `/admin/metrics` обновились.
7. **Права**: студентом открыть `/admin` — пункта меню нет; прямой переход → ядро отвечает 403 с русским текстом (показывается плашкой).
