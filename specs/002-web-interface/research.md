# Phase 0 — Research: веб-интерфейс (002)

## R1. Навигация без роутера

- **Decision**: `App.jsx` хранит `view` (строка) + `session` (user из `/api/auth/me`). Переходы — функции `go(view)`. Админские представления доступны при `user.role === "operator"`, иначе скрыты.
- **Rationale**: одна страница, демо, ноль зависимостей.
- **Alternatives considered**: `react-router-dom` (стандарт, но +1 зависимость и boilerplate ради 9 экранов без URL-шаринга).

## R2. Сессия и запросы

- **Decision**: `api.js` — обёртка над `fetch`: `credentials: "include"`, JSON, при 401 → сброс в `LoginView`. Ошибки ядра (`{detail}`) показываются как есть (они уже по-русски).
- **Rationale**: cookie-сессия ядра (R4 из research 001) прозрачно работает через Vite-прокси.
- **Alternatives considered**: localStorage-токен + заголовок (ломает модель cookie ядра).

## R3. Опрос обновлений (статусы, статус-борд, метрики)

- **Decision**: лёгкий polling `setInterval` 5 c в представлениях кабинета, админ-очереди и статус-борда; остановка при уходе с представления (cleanup).
- **Rationale**: смена статуса справки оператором должна быть видна пользователю без F5 (FR-022/FR-033); websocket/sse — избыточно для демо.
- **Alternatives considered**: SSE/WebSocket (красиво, но +серверный канал в ядре — вне 6 часов).

## R4. Диалог уточнений

- **Decision**: диалог — массив сообщений `{role, text}` из `GET /api/requests/{id}` + локальное добавление реакций из `POST /api/requests*`; состояние «ждёт ответа пользователя» включает поле ввода ответа, иначе — только чтение.
- **Rationale**: прямой маппинг на контракт; «в том же окне без потери контекста» (FR-012).
- **Alternatives considered**: отдельный чат-компонент с библиотекой (избыточно).

## R5. Оформление

- **Decision**: наследуем тёмную тему `App.css`; семантические акценты: priority (critical=красный, high=оранжевый, medium=жёлтый, low=серый), route-значки (⚙ авто / 📖 база знаний / 📄 справка / 👤 оператор), извещение о сбое — заметная красная плашка (FR-013), статус-борд — зелёные/красные лампочки.
- **Rationale**: «красиво и заметно» без дизайн-системы; emoji-значки читаемы на проекторе.
