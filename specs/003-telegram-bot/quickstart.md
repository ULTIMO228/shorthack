# Phase 1 — Quickstart: Telegram-бот (003)

## Разовая настройка (5 минут)

1. В Telegram: `@BotFather` → `/newbot` → имя (напр. `MISIS Support Demo`) и username (`..._bot`) → получить токен.
2. Узнать chat_id дежурного: написать своему боту `/start` с личного аккаунта «дежурного», затем `curl https://api.telegram.org/bot<ТОКЕН>/getUpdates` → взять `message.chat.id`.
3. `backend/.env` (не коммитим):
   ```
   TG_BOT_TOKEN=<токен от BotFather>
   TG_DUTY_CHAT_ID=<chat_id дежурного>
   BOT_INTERNAL_TOKEN=<та же строка, что в .env ядра>
   CORE_API_URL=http://localhost:8000
   ```

## Запуск

```bash
# 1) Ядро (001) — обязательно запущено:
cd backend && .venv/bin/uvicorn app.main:app --reload   # :8000

# 2) Бот (отдельный терминал/процесс):
cd backend && .venv/bin/python -m app.bot.main
# ожидаемый вывод: "bot started, polling as @<username>; duty chat <id>"
```

## Сценарии проверки (приёмочный чек-лист — contracts/bot-contract.md §6)

1. **Привязка**: новый аккаунт → `/start` → приветствие → ввод `ivanov@misis.ru` → «код отправлен» → ввод кода (берётся из ответа `POST /api/internal/tg/link` или из админки) → «Готово, Иван!».
2. **Обращение-уточнение**: «не открывается сайт» (сайт жив) → «Принял, разбираю…» → уточняющий вопрос → ответ «хром, ошибка 404» → продолжение разбора без повтора проблемы.
3. **Извещение о сбое**: оператором в админке 002 выключить MISIS-EDU → в боте «не работает вайфай edu» → 🔴 извещение.
4. **Справки**: `/certs` → кнопка «Справка с места учёбы» → «Заказать» → ✅ с номером; тот же заказ виден в админке 002 и в кабинете на сайте; `/certs` → «Мои заказы» → статус.
5. **Статус**: `/status` → список с номерами SUP-2026-*.
6. **Дежурный**: в админке 002 — `simulate_wave` → в чат дежурного падает «🔴 Инцидент: …» ≤ 1 мин.
7. **Устойчивость**: остановить ядро → «не работает lms» → T13 «сервис недоступен»; поднять ядро → следующий запрос проходит без рестарта бота.

## Тесты

```bash
cd backend && .venv/bin/python -m pytest tests/test_bot_handlers.py -v
```

Юнит-тесты без сети: разбор команд, состояния автомата, форматирование `/status` и `/certs`, разбиение длинных сообщений (моки `tg.py` и `core_api.py`).

## Границы

Бот не работает без ядра (001) — это тонкий канал. Веб-интерфейс (002) для сценариев нужен только в роли оператора (переключение сервисов, simulate_wave, просмотр заказов) — там, где сказано «оператором».
