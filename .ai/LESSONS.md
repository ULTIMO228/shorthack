# LESSONS (Shorthack) — ошибки которые нельзя повторять

## L001 | Vite proxy ≠ реальный путь редиректа
❌ В `vite.config.js` прокси настроен на `/s`, а бэкенд отдаёт `short_url: "/{code}"`
✅ Либо проксировать `/{code}` нельзя (перехватит всё) — либо бэкенд должен отдавать `/s/{code}`
! Пока работает в dev, потому что редирект идёт напрямую на :8000. FIX: unified prefix `/s/`

## L002 | Сессии SQLAlchemy не закрываются
❌ В каждом эндпоинте `session = Session()` без `close()` → утечка соединений под нагрузкой
✅ `with Session() as session:` (контекстный менеджер) или Depends + yield
! SQLite терпит, PostgreSQL зато нет — чинить ДО миграции на Postgres

## L003 | random.choices ≠ криптостойкий
❌ Предсказуемые коды = перебор чужих ссылок
✅ `secrets.token_urlsafe(4)` для прод-кодов, random только для dev
! Не критично для MVP без приватных ссылок, критично для Pro-плана

✅ `git add` конкретные файлы
